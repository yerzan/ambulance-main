# ADR-001: Вибір рушія

- **Статус:** Прийнято (рішення власника проєкту)
- **Дата:** 2026-11-19
- **Задача:** LC-001

## Контекст
GDD v1.1 залишав вибір між Unity та Unreal відкритим (розділ 13) і водночас згадував Unity у змісті.
Потрібно зафіксувати єдине рішення до початку production.

## Рішення
**Unity 6.7 + URP**, мова C#.
Мережа (за замовчуванням, підтвердити першим мережевим прототипом, LC-009):
Netcode for GameObjects 2.x + Unity Multiplayer Services SDK (Sessions/Lobby/Relay); voice — Vivox (рішення окремо).

## Відомі питання до перевірки
- GDD описував шлях на Unity 6.3 LTS. Перевірити в Unity Hub / https://unity.com/releases/editor/archive, чи 6.7 є LTS чи Update-релізом, і зафіксувати **точну** версію (`ProjectVersion.txt`).
- Перевірити сумісність NGO 2.x та Multiplayer Services SDK з обраною версією редактора.
- Якщо мережева фізика нош/NPC не пройде перевірку в LC-009 — переглянути рішення в окремому ADR.

## Наслідки
- Розділи 13–14 GDD застосовуються як є (ScriptableObjects, asmdef, NGO).
- Unreal-варіанти в GDD більше не розглядаються для першої версії.
- Версію рушія змінюємо лише через новий ADR.
